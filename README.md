# Lab 2 : Construire un écran “About” avec View et Tex
## Objectif : 
Réaliser une interface mobile simple en utilisant les composants de base de React Native.

## Travail réalisé

Dans ce TP, nous avons créé une application React Native composée de trois composants :

AppHeader : affiche le titre de l'application.

AboutScreen : affiche un titre, un sous-titre et un paragraphe descriptif.

AppFooter : affiche un message de droits réservés.

Nous avons utilisé les composants View et Text, ainsi que StyleSheet pour organiser et personnaliser l'interface. Nous avons également utilisé flex, padding, margin et justifyContent pour gérer la mise en page.
